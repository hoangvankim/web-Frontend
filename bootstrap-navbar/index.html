Thực Hành Bootstrap 5 Navbar

Thanh điều hướng chuyên nghiệp, hỗ trợ menu thả xuống (Dropdown) và nút thu gọn (Toggler) responsive trên mọi thiết bị.

1. Navbar Brand

Định dạng logo thương hiệu hoặc tên website với class .navbar-brand.

2. Dropdown Menu

Tạo menu đa cấp bằng .dropdown-toggle và .dropdown-menu kết hợp với Bootstrap JavaScript.

3. Mobile Toggler

Tự động thu gọn menu thành nút 3 gạch (hamburger) khi kích thước màn hình nhỏ hơn 992px (breakpoint -lg).
