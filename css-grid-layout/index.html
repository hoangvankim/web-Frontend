Nội Dung Chính

Trang web này sử dụng CSS Grid với thuộc tính grid-template-areas để thiết kế bố cục chia vùng trực quan và mạch lạc.

Trên màn hình máy tính (Desktop), Sidebar chiếm 1 phần (1fr) và Content chiếm 3 phần (3fr). Khi thu nhỏ trình duyệt xuống dưới 768px (Mobile), bố cục sẽ tự động chuyển thành dạng dọc 1 cột duy nhất.
