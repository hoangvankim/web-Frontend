Bài Thực Hành: 3 Cách Nhúng CSS Vào Trang Web

Phần 1: Sử dụng Inline Style (CSS trực tiếp trong thẻ)

Tiêu đề đổi màu bằng Inline CSS (Màu đỏ)

Đoạn văn bản này được định dạng màu sắc trực tiếp qua thuộc tính style trong thẻ p.

Phần 2: Sử dụng Internal Style (CSS trong thẻ style ở thẻ head)

Tiêu đề đổi màu bằng Internal CSS (Màu xanh lá)

Đoạn văn bản này được định dạng màu sắc thông qua thẻ style nằm trong phần head của trang.

Phần 3: Sử dụng External Style (CSS từ tệp style.css bên ngoài)

Tiêu đề đổi màu bằng External CSS (Màu xanh dương)

Đoạn văn bản này được định dạng màu sắc thông qua tệp style.css riêng biệt liên kết bằng thẻ link.
